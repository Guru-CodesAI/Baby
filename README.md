## ✨ Welcome to the Midnight Nursery

Meet **Pip** — a curious, sleepy skull baby and Junior Dream Engineer at the Midnight Nursery. Pip makes little inventions for bedtime: soft lullabies, glowing nightlights, and dreams delivered across a cozy rooftop neighborhood.

**Pip’s Midnight Nursery** turns that character into an interactive portfolio: part bedtime storybook, part tiny dream workshop, with playful details to discover along the way.

> 🌟 *Even the smallest star needs somewhere soft to land.*

## 🎨 A little design philosophy

The visual direction is built around the warmth of a nursery at bedtime, with a playful early-web spirit.

- **Palette:** warm cream, berry, chocolate brown, lavender, soft pink, and honey gold.
- **Typography:** Fraunces for expressive display text, DM Sans for readability, and Fredoka for playful accents.
- **Motion:** gentle, purposeful animation designed to add atmosphere rather than get in the way.
- **Interaction:** the dream-cloud can also be activated with a keyboard; reduced-motion preferences are respected.
- **Character:** Pip stays cute, cozy, and friendly — never creepy or frightening.

The intention is simple: **make the interface feel like part of Pip’s world, not a generic portfolio template.**

## 🚀 Run it locally

No framework setup, package installation, or build command is required for the standalone page.

1. Clone or download the repository:

   ```bash
   git clone https://github.com/Guru-CodesAI/Baby.git
   cd Baby
   ```

2. Open **`Pip’s Midnight Nursery.html`** in a modern browser.

   You can also open the HTML file directly from your file manager.

### A note about offline use

The main page, its HTML/CSS, and its embedded illustrations are included in the HTML file. **Google Fonts and Three.js load from external CDNs**, so those enhancements require an internet connection. Without a connection, the external fonts or 3D library may not load.

## ☁️ Deploy to Vercel

This is a static site. The repository includes [`vercel.json`](./vercel.json), which routes the site root to the nursery page.

1. Open [Vercel](https://vercel.com/new) and import [`Guru-CodesAI/Baby`](https://github.com/Guru-CodesAI/Baby).
2. Choose **Other** as the framework preset if Vercel asks.
3. Leave the build command empty; this project does not require a build step.
4. If an output directory is requested, use the repository root (`.`).
5. Deploy, then open the production URL and test the site on desktop and mobile.
